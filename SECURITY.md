## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues by emailing **security@laraarabdev.com**.

Include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

**Response timeline:**
- Acknowledgement within **48 hours**
- Status update within **7 days**
- Fix and coordinated disclosure within **90 days** of confirmed report

We follow [responsible disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure). Thank you for helping keep this project secure.

## الإبلاغ عن ثغرة أمنية

**لا تفتح** Issue عامة على GitHub للثغرات الأمنية.

أبلغ عن المشاكل الأمنية عبر البريد الإلكتروني: **security@laraarabdev.com**

يرجى تضمين أكبر قدر ممكن من التفاصيل:
- وصف الثغرة الأمنية
- خطوات إعادة الإنتاج
- التأثير المحتمل
- الإصلاح المقترح (اختياري)

**الجدول الزمني للاستجابة:**
- الإقرار بالاستلام خلال **48 ساعة**
- تحديث الحالة خلال **7 أيام**
- الإصلاح والإفصاح المنسق خلال **90 يوماً** من تأكيد البلاغ

نتبع سياسة [الإفصاح المسؤول](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure). شكراً لمساعدتك في الحفاظ على أمان هذا المشروع.
